Hangar 初始化

首次部署需要完成以下设置，之后即可正常使用。

⚠ 此工具仅适合内网环境部署，不要暴露在公网上。 登录 Token 以明文存储在容器数据库中，公网暴露存在安全风险。

登录 Token

用于 WebUI 登录和 API 鉴权（X-API-Key），不能为空。

请务必记好此处设置的 Token！初始化完成后页面不会再次显示。 若遗忘，在容器内执行 cat /data/token.txt 即可查看。

硬枚举字段

类别与状态为受限选项（写入时校验），初始化时可自由修改，默认值仅供参考。

软枚举字段

以下字段为自由文本，这里填写的内容仅作为输入建议。可全部留空，之后随记录自由填写。

高德地图 API Key（可选）

填写后照片 GPS 位置将显示为地址；留空则仅显示坐标。
